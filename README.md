# Tibia Task or Sell

Web app para comparar el valor de vender items al NPC, venderlos en Market o usarlos para Delivery Tasks en Tibia.

## Objetivo
Ayudar a jugadores de Tibia a decidir qué hacer con sus items de Delivery Task según:
- precio NPC
- precio Market
- experiencia obtenida por task
- dificultad de la task
- nivel del personaje

## MVP inicial
- Base de datos local en JSON de Delivery Task items
- Cálculo de NPC vs Market
- Cálculo de XP por level y dificultad
- Recomendación básica

## Estructura prevista
- `data/` para datos estáticos del juego
- `app/` o `src/` para la aplicación web
- `scripts/` para limpieza y validación de datos
